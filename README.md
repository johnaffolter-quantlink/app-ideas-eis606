# App Ideas — EIS 606 Homework 1

A list of app ideas I might "vibe code" (build quickly with AI-assisted coding tools, prototyping fast and iterating by feel rather than a full spec). Each one below is sharpened using a couple of TRIZ inventive-principle "lenses" (a classic engineering brainstorming framework) to push past the first-draft version of the idea. Idea 9, **Qurve**, is the one I'm developing further for Homework 2.

1. **Macro Pulse** — *TRIZ: Feedback, Local Quality.* Pulls a handful of public macro indicators (CPI, rates, PMI) and auto-generates a plain-English "what changed this week and why it matters" digest instead of raw charts. Each indicator carries its own reliability tag (not all sources are equally trustworthy), and a feedback loop lets you mark changes that actually mattered so future digests get sharper.

2. **Notebook-to-Slide** — *TRIZ: Segmentation, Continuity of Useful Action.* Breaks a data notebook into small, independently-refreshable blocks, then assembles them into a slide deck. Because each slide stays wired to its source query, the deck keeps doing useful work — staying current — long after the "build" step, instead of going stale the moment it's exported.

3. **Ontology Mapper** — *TRIZ: Prior Action, Universality.* Suggests how columns from two messy CSVs map to a shared schema, pre-computing likely matches from common field-name patterns before you even ask, and using the same mapping engine whether the source is a spreadsheet, CSV, or API payload.

4. **Habit Ledger** — *TRIZ: Dynamicity, Self-Service.* A savings tracker that treats goals like "positions" you're building toward. Pacing adjusts automatically if you get ahead or behind, and it pulls from linked accounts rather than requiring manual entry every time.

5. **Meeting Memory** — *TRIZ: Segmentation, Feedback.* Records a meeting and builds a searchable, linked map of decisions and open questions instead of a flat transcript. Each decision node links back to the moment it was made, and flags questions that were raised but never resolved.

6. **Recipe Remix** — *TRIZ: Prior Action, Local Quality.* Enter the ingredients you already have on hand and get recipes ranked by how few substitutions or extra trips to the store they'd require, with substitution suggestions tailored to what's actually in your pantry.

7. **Study Buddy** — *TRIZ: Segmentation, Feedback.* Upload lecture slides or readings and automatically generate spaced-repetition flashcards for exam prep, with the review schedule adjusting based on which cards you're actually getting wrong.

8. **Local Deals Radar** — *TRIZ: Merging, Local Quality.* Aggregates local events and discounts (Twin Cities area) into one weekly digest instead of checking five different sites, ranked by relevance to your own past interests rather than shown as one generic list.

9. **Qurve** — *TRIZ: Merging, Universality.* An AI-native dev workspace that merges a code-aware knowledge graph (RAG over the codebase), task tracking, team chat, and an embedded coding agent into one product built around a single shared graph of code, tasks, and conversations — instead of stitching those together across four separate tools. Initial specs written up separately for Homework 2.
