# App Ideas — EIS 606 Homework 1

A list of app ideas I might "vibe code" (build quickly with AI-assisted coding tools, prototyping fast and iterating by feel rather than a full spec). Each one below is sharpened using a couple of TRIZ inventive-principle "lenses" (a classic engineering brainstorming framework) to push past the first-draft version of the idea. Idea 9, **Skein**, is the one I'm developing further for Homework 2.

1. **Macro Pulse** — *TRIZ: Feedback, Local Quality.* Pulls a handful of public macro indicators (CPI, rates, PMI) and auto-generates a plain-English "what changed this week and why it matters" digest instead of raw charts. Each indicator carries its own reliability tag (not all sources are equally trustworthy), and a feedback loop lets you mark which changes actually mattered so future digests get sharper.

2. **Notebook-to-Slide** — *TRIZ: Segmentation, Continuity of Useful Action.* Breaks a data notebook into small, independently-refreshable blocks, then assembles them into a slide deck. Because each slide stays wired to its source query, the deck keeps doing useful work — staying current — long after the "build" step, instead of going stale the moment it's exported.

3. **Ontology Mapper** — *TRIZ: Prior Action, Universality.* Suggests how columns from two messy CSVs map to a shared schema, pre-computing likely matches from common field-name patterns before you even ask, and using the same mapping engine whether the source is a spreadsheet, CSV, or API payload.

4. **Habit Ledger** — *TRIZ: Dynamicity, Self-Service.* A savings tracker that treats goals like "positions" you're building toward. Pacing adjusts automatically if you get ahead or behind, and it pulls from linked accounts rather than requiring manual entry every time.

5. **Meeting Memory** — *TRIZ: Extraction, Intermediary.* Pulls out just the decisions and open questions from a meeting recording — not the full transcript — and acts as a searchable go-between that links each decision back to the exact moment it was made.

6. **Recipe Remix** — *TRIZ: Segmentation, Substitution.* Breaks a recipe into swappable ingredient "slots" and ranks results by how few slots need substituting given what's already in your kitchen.

7. **Study Buddy** — *TRIZ: Segmentation, Periodic Action.* Splits lecture slides or readings into flashcard-sized chunks and resurfaces each one on a spaced-repetition schedule tuned to how well you already know it, rather than a fixed calendar.

8. **Local Deals Radar** — *TRIZ: Merging, Periodic Action.* Merges multiple local event and discount sources (Twin Cities area) into one weekly digest instead of checking five different sites.

9. **Skein** — *TRIZ: Merging, Universality.* An AI-native dev workspace that merges a code-aware knowledge graph (RAG over the codebase), task tracking, team chat, and an embedded coding agent into one product built around a single shared graph of code, tasks, and conversations — instead of stitching those together across four separate tools. Initial specs written up separately for Homework 2.
